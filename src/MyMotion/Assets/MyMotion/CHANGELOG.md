# Changelog

## 1.0.0 - 2026-11-25

First public release.

- LitMotion-compatible tween API: `MMotion`, `MSequence`, `MotionBuilder`, `MotionHandle`, schedulers, and adapters.
- Burst-compiled, zero-allocation runtime with pipelined evaluation and binding.
- Value types: float, double, int, long, Vector2/3/4, Quaternion, Color, Rect, FixedString, and custom types through `IMotionAdapter`.
- Punch, Shake, and string motions.
- `async`/`await`, coroutines, `Awaitable`, and `ValueTask` support.
- Optional integrations: uGUI, TextMeshPro, UI Toolkit, SRP Volume, Visual Effect Graph, UniTask, R3, UniRx.
- Animation components (`MyMotion Animation`) and the Motion Debugger window.
- Installation through Unity Package Manager (Git URL).
